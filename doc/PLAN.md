# 正法眼蔵プロジェクト 統合プラン

本文書は、Web サイト（学習・漫画・コンテンツ）、問答 Bot（RAG）、バックエンド基盤（Quarkus / Camel / Llama Stack / OpenAI）、およびデプロイ方針を一つのプランとして整理したものです。

---

## 1. 目的とスコープ

### 1.1 目的

- 道元『正法眼蔵』（現代語訳テキスト等）を、**読める・問える・振り返れる**形で提供する。
- **教育的視点**（足場かけ、多様な表象、形成評価）と**漫画等の視覚メディア**で理解の入口を広げる。
- **正法眼蔵に根拠づけた問答**を行う Bot を、RAG で実現する。

### 1.2 コーパス

- リポジトリ内: `doc/正法眼蔵.txt`（目次・七十五巻・十二巻・辨道話等を含む全文系テキスト）、全訳 PDF。
- 取り込み・公開・索引化の対象は、**著作権・利用許諾の範囲内**のデータに限定する。

## 2. Web サイト構成（情報設計）

### 2.1 想定読者

- 初見の一般読者、実践者、教育者・学生。

### 2.2 サイトマップ（案）

| 領域 | 主なページ | 役割 |
|------|------------|------|
| 入口 | ホーム | プロジェクト紹介、学び方のコース案内、おすすめ巻 |
| 学習支援 | はじめに / 学習ガイド | 文体の特徴、サイトの使い方、授業での使い方（教育者向け節） |
| 本文 | 巻一覧 | 七十五巻・十二巻・辨道話への導線、タグ・難易度 |
| 本文 | 各巻ページ | 導入、語彙、本文（現代語）、深掘り、確認クイズ、問いの種 |
| 横断 | 用語辞典・テーマ別入り口 | 検索と関連巻へのリンク |
| 対話 | 問答 Bot UI | 巻スコープ、出典表示、免責 |
| 運用 | サイト情報 | 利用テキストの版、クレジット、プライバシー |

### 2.3 教育的視点の組み込み

- **足場かけ**: 各巻の前に語彙・歴史的一文・読み方のヒント。
- **認知段階（Bloom のイメージ）**: 用語・要約（記憶・理解）→ 生活・実践への橋渡し（応用）→ 他巻・他解釈との関係（分析）→ 問い・Bot 対話（評価・創造のきっかけ）。
- **多様な表象**: テキスト、図解、**漫画**、（将来）音声。
- **形成評価**: 巻末クイズ、用語カード、Bot 対話でのヒント返し。
- **メタ認知**: 「一度にすべてを理解しなくてよい」道元読解のガイド。

### 2.4 漫画・イラストの位置づけ

- **概念マンガ**（巻末 4〜8 コマ程度）: 比喩・場面の視覚化。本文とは別レイヤーとし、**必ず本文・要約へリンク**（漫画のみで教義を断定しない）。
- **制作フロー（案）**: 脚本（内容監修）→ ラフ→ 線画／公開。誤読の固定化を防ぐレビューゲートを設ける。

## 3. 問答 Bot と RAG アーキテクチャ

### 3.1 基本方針

- **Llama Stack**を AI アプリケーションサーバー（OpenAI 互換 API、RAG・エージェント・ベクトルストア等）として利用する。
- **推論は OpenAI**（API キーはサーバー側のみ。クライアントには渡さない）。
- **Quarkus（JDK 21）**が外向き API・認可・レート制限・会話メタデータ・監査ログの境界となる。
- **Apache Camel 4**が Llama Stack・RDB・Web 検索等との**統合ルート**（変換、再試行、サーキットブレーカ、将来の他システム接続）を担う。

### 3.2 論理構成

```
[クライアント]
    → [Quarkus REST] → [Camel ルート]
          → [Llama Stack :8321/v1 …] → [OpenAI]
          → [PostgreSQL（業務・監査・会話メタ）]
          → [ベクトル検索: Qdrant（Llama Stack `remote::qdrant`）]
          → [Web 検索: ツールまたは Camel 前置検索]
```

- **RAG の中核**（チャンク検索＋生成のオーケストレーション）は Llama Stack に寄せ、Quarkus/Camel は**ポリシー・永続化・外部 I/O の配線**に集中する。

### 3.3 データとチャンク

- チャンク単位: 現代語訳の段落優先。メタデータ例: `volume_id`, `title`, `paragraph_id`, `source`。
- **回答は根拠チャンクに紐づける**（出典表示。根拠が薄い場合は推測と明示、または拒否）。

### 3.4 Web 検索

- **Llama Stack のツール**として実行するか、**Camel が先に検索**してから Llama Stack に渡すかを選択可能。
- 宗教・教育文脈ではノイズが大きいため、**正法眼蔵チャンク優先**、Web は補助かつ引用ルールを厳しめにする方針を推奨。

### 3.5 品質・安全

- 代表質問セットでの評価（出典一致率、拒否率、ユーザー評価）。
- 高頻度 FAQ は**編集確定回答のキャッシュ**を検討。
- 実践・心の健康に関する相談は人間の指導を推奨する免責を UI に明示。

## 5. デプロイ・運用プラン

### 5.1 ローカル

- `deploy/local/compose.yaml`: PostgreSQL ＋ **Qdrant** ＋ Llama Stack イメージ。
- `deploy/local/env.example` を `.env` にコピーし、`OPENAI_API_KEY` を設定して起動。
- 手順の詳細: **`deploy/README.md`**。

### 5.2 OpenShift

- Secret（API キー、DB パスワード）、Deployment/StatefulSet、Service、PVC。
- 外向き HTTP は Quarkus に Route。Llama Stack は ClusterIP。
- ネットワークポリシーで Quarkus のみが Llama Stack のポートに到達可能にする案を推奨。

### 5.3 バージョン管理

- Llama Stack イメージは**リリースタグでピン留め**（例: `0.7.1`）。追従時は `latest` + 定期 `pull` と回帰テスト。
