問答 Bot

バックエンド dogen-chat（Quarkus + Camel）経由で Llama Stack のチャット補完 API に接続します。会話は PostgreSQL の chat_session / chat_message に保存され、セッションを選び直して続きから話せます。

使い方：どのページからでも画面右下の 「問答」ボタンでパネルを開きます。セッション一覧から過去の会話を選ぶか、「新規」で別スレッドを始められます。静的ファイルは python3 -m http.server -d web などで HTTP 配信してください。API は既定 http://127.0.0.1:8081（window.DOGEN_CHAT_API_BASE で変更）。
ログイン（OIDC）：各ページのナビに ログインが表示されます（web/js/oidc-config.js で enabled: true と IdP の authority / client_id を設定したとき）。PKCE で IdP の画面へ飛び、戻りで localStorage.dogen_bearer_token にアクセストークンが入ります。API 側は QUARKUS_PROFILE=compose,oidc 等で Bearer 検証を有効にしてください。全体の流れは 認証の流れ（OIDC） を参照。
免責：回答は学習補助です。宗教的実践や心の健康の判断は人間の指導に任せてください。404 で Model … not found のときは Llama Stack のモデル ID（例: openai/gpt-4o-mini）に DOGEN_CHAT_DEFAULT_MODEL を合わせ、GET …/v1/models で確認してください。

API（参考）

  • POST /api/v1/chat … 本文に sessionId（UUID）と messages（今回の user だけで可）を含めると履歴とマージされます。
  • POST /api/v1/chat/stream … text/event-stream で逐次応答（delta / done）を受信します。
  • GET /api/v1/sessions … 保存済みセッション一覧。
  • GET /api/v1/sessions/{id}/messages … そのセッションのメッセージ履歴。
