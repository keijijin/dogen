図解・画像の方針（拡張）

巻ページの図・4コマは原則 web/img/*.svg のベクタで置き、拡大しても劣化しないようにします。ラスタ画像が必要なときは、編集者が許諾のある素材を web/img/ に追加する運用とします。

画像生成 LLM の利用（任意拡張）：バックエンドに「プロンプトを受け取り画像 API（OpenAI Images、他社モデル等）を呼ぶ」エンドポイントを増やし、編集者用またはキャッシュ済みアセット生成に限定する形が安全です。公開ページから任意ユーザーに生成させる場合は、レート制限・コンテンツポリシー・著作権表記を必須とします。現状リポジトリにはその API は含めていません。
