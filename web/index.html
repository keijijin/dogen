このサイトでの読み方（目安の順）

  1. 語彙の足場 — 巻ごとの用語を先に押さえ、誤読のレールを外す。
  2. 本文（冒頭抜粋） — 道元の語順・反語に触れる。
  3. 図解・イラスト — 骨格や場面の視覚化（本文の代替ではありません）。
  4. 深掘り・確認クイズ — 要点の言語化と振り返り。
  5. 問答 Bot — 巻や用語を指定して問う（出典・免責は各ページの案内に従う）。

一度にすべてを終える必要はありません。心構えは学習ガイドにまとめています。
